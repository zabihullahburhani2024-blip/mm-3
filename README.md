## API
- فقط **Twelve Data** (`XAU/USD`)
- کلید: `c04c9c4a7e6845f380c5e60cf59852ff`
- رفرش: **۸ بار در دقیقه** (هر ۷٫۵ ثانیه)
- سهمیه روزانه رایگان: ۸۰۰

## احراز هویت (بدون سرور)
1. کاربر از منو → پاسه فروشان → ثبت‌نام
2. یک کد ۳۲ رقمی از استخر ۱۰۰۰تایی اختصاص می‌یابد
3. دکمه «ارسال با واتساپ» لینک `wa.me` باز می‌کند (کد در پیام)
4. پرداخت فیزیکی → تحویل/تأیید کد → فعال‌سازی در برنامه
5. بازیابی رمز با پاسخ بازیابی ذخیره‌شده در دستگاه

کدها در `js/codes.js` و کپی در `data/activation_codes.json`.
